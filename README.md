# Procurement EBR | WNS × Telkom H1 FY27

React (Vite) app for the WNS × Telkom H1 FY27 Executive Business Review.

- Content: `src/data.js` (all text, numbers and charts for this domain)
- Links to the other domain apps: `src/domains.js`
- Run locally: `npm install && npm run dev`
- Deploy: import the repo in Vercel (framework: Vite, output: dist)
